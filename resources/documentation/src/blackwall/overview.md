# Overview

Beelink ME Pro N150 private server hosting game servers, web servers, media servers and NAS.

Named after the [Blackwall](https://cyberpunk.fandom.com/wiki/Blackwall) from Cyberpunk 2077.

## Hardware

```
Device:   Beelink ME Pro N150
Storage:  1TB NVMe (OS & configs)
          1TB 3.5" SATA (Nextcloud Data)
```

## Services

- Astro.js webpage
- AdGuard Home (DNS, routing, firewall)
- Jellyfin Media Stack, TubeArchivist & Tunarr
- Nextcloud NAS
- Soulseek/Nicotine+
- Private Mastodon instance
- Authentik identity management
- Home Assistant
- Gitea
- n8n/local LLM
- Homebox
- Mealie
- WireGuard
- code-server
