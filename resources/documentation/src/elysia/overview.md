# Overview

Small form factor desktop PC for gaming, development and productivity.

Named after [Rache Bartmoss](https://cyberpunk.fandom.com/wiki/Rache_Bartmoss)' Cyberdeck.

## Hardware

```
Case:     Meshroom S
CPU:      Intel i7-12700KF @ 5GHz
GPU:      GigaByte GeForce RTX 4070TI
RAM:      32GB DDR5 @ 6000MHz
Storage:  2TB NVMe (Windows 10)
          256GB NVMe (NixOS)
```

## Features

- GRUB dual-boot with Windows
- Wayland/GNOME desktop
- NVIDIA proprietary drivers
- Docker and Podman

## Home Manager

- Fish shell with Kitty
- VS Code, Obsidian, LibreOffice
- Steam, PrismLauncher
- Tor Browser, ProtonVPN
